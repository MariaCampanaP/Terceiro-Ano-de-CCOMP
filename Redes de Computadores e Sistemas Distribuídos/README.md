# ☕︎︎ Redes de Computadores e Sistemas Distribuídos

Repositório contendo exercícios da disciplina **Redes de Computadores e Sistemas Distribuídos** do terceiro ano de **Ciência da Computação** na UNESPAR.

## ☕︎︎ Sobre o Repositório

Este repositório reúne implementações de conceitos fundamentais da **Redes de Computadores e Sistemas Distribuídos**, abordando tópicos como:

- *Cliente*
- *Servidor*

## ☕︎︎ Objetivo

Os códigos servem como material de estudo e prática para reforçar os conceitos abordados na disciplina.

## ☕︎︎ Tecnologias Utilizadas

- Python;
- Visual Studio Code.

## ☕︎ Como Usar

## Como clonar apenas esta pasta

Este repositório contém todas as disciplinas do 3° ano. Se quiser baixar **somente** a pasta "Redes de Computadores e Sistemas Distribuídos", use o sparse-checkout do Git:

```bash
git clone --no-checkout https://github.com/MariaCampanaP/Terceiro-Ano-de-CCOMP.git
cd Terceiro-Ano-de-CCOMP
git sparse-checkout init --cone
git sparse-checkout set "Redes de Computadores e Sistemas Distribuídos"
git checkout main
```
